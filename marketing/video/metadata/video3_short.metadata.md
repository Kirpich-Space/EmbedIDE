## Title

EmbedIDE in 45 seconds: a native Rust terminal IDE with AI agents #shorts

## Description

EmbedIDE (`embed`) is a native Rust IDE for embedded and systems development that runs in your terminal. Real recording of version 0.1.0-alpha.1: build with GCC, jump to the error, fix it, then let an AI agent (Claude Code / Codex CLI, your own login) add a function, build and run it.

Official Kirpich Space / EmbedIDE video. Alpha: Linux verified, FreeBSD compiles but not yet run, no Windows/macOS, native GUI planned.

https://github.com/Kirpich-Space/EmbedIDE  (GPL-3.0)
Install: curl -fsSL https://raw.githubusercontent.com/Kirpich-Space/EmbedIDE/main/install.sh | sh
